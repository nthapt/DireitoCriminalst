# ⚖️ Website / Interface - Advocacia Criminalista

Uma interface web elegante, moderna e altamente funcional desenvolvida para apresentar os serviços de uma **Advogada Criminalista**. O projeto foi desenhado para transmitir credibilidade, autoridade, seriedade e acessibilidade jurídica aos clientes.

---

## 🎯 Sobre o Projeto

O objetivo deste projeto é oferecer uma experiência de navegação intuitiva e segura para potenciais clientes em momentos delicados e decisivos. A interface foca no posicionamento de marca pessoal da advogada, destacando áreas de atuação, ética profissional, atendimento humanizado e canais de contato rápido (como integração direta para emergências criminais).

---

## ✨ Funcionalidades Principais

* **Hero Section Impactante:** Apresentação da advogada com proposta de valor clara e chamada para ação (*CTA*) imediata.
* **Atendimento de Emergência (24h):** Botão fixo/de destaque para contato rápido via WhatsApp/Telefone para prisões em flagrante ou emergências policiais.
* **Áreas de Atuação:** Seção detalhando especialidades (Direito Penal, Tribunal do Júri, Crimes Empresariais, Execução Penal, etc.).
* **Sobre a Profissional:** Espaço para trajetória acadêmica, conquistas e posicionamento ético.
* **Formulário de Contato Direto:** Permite o envio de mensagens para agendamento de consultas ou análise prévia do caso.
* **Layout Totalmente Responsivo:** Adaptado para perfeita visualização em computadores, tablets e smartphones.

---

## 🎨 Design & Tipografia

* **Paleta de Cores:**
  * **Tons Escuros (Azul Marinho / Preto):** Transmitem autoridade, seriedade, elegância e segurança.
  * **Dourado / Bege:** Trazem sofisticação e remetem à tradição e justiça.
  * **Branco / Cinza Claro:** Garantem excelente legibilidade e contraste nos textos.
* **Tipografia:** Combinação de fontes com serifa (para títulos, conferindo tom solene e tradicional) e sem serifa (para o corpo do texto, garantindo clareza e modernidade na leitura).
